Executed code and the summary tables it wrote. Raw GDSC2, PRISM and DepMap matrices are not included; `run_decomposition.py` expects them under the external paths recorded in `docs/DATA_SOURCES.md` and `docs/REPRODUCIBILITY.md`. This directory is not a one-command raw-data rerun.

- TSV and `summary.json` files here and in `prism/`: the executed GDSC2 and PRISM outputs.
- `manuscript_tables/`: Supplementary Tables S8–S10 as deposited with the manuscript. They were assembled from these outputs and were not recomputed for this release.
